# Project Rules

- **Commit Cleanliness**: Never commit automation scripts, scrapers, or helper utilities (like screenshot generators, Playwright scripts, etc.) directly to the repository unless explicitly asked. These should remain in local scratch space to preserve a clean and organic showcase presentation.
- **Git Commit Messages**: Avoid AI-style conventional commits (e.g., prefixes like `feat:`, `fix:`, `chore:`, `docs:`). Use natural, human-like commit descriptions that match the owner's style (e.g., "Add UECFI Church Hymnal & Lyrics showcase").
