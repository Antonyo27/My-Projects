Visual assets used throughout the showcase repository.

## Files to add

| File | Purpose | Recommended dimensions |
|------|---------|------------------------|
| `banner.png` | Top banner displayed in the root `README.md` | 1500 × 500 px (3:1 ratio) |
| `profile.png` | Optional profile/avatar image | 400 × 400 px (square) |

## `tech-stack-icons/`

Drop your tech stack icons here if you'd like to use local SVGs/PNGs instead of shields.io badges. The current root README uses shields.io which requires no local files — this folder is provided for future flexibility.

Suggested naming convention: `<tech>.svg` (lowercase, hyphenated). E.g., `laravel.svg`, `react.svg`, `tailwind-css.svg`.
